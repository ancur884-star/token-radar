How the value is made

Implied value is an expected value: the peer-implied value of a token if it launched today, times the snapshot-derived odds that it ever launches. It is this entry's claim, never a prediction that a token will be issued, or when.

implied = TVL × peer multiple × growth × maturity × launch odds

What this radar does not claim

  • “Records no token” means DefiLlama's record carries no token — not that the protocol has none. A protocol on the board may still have a token its record does not carry.
  • A farm plan is not a promise of an airdrop. A token is not guaranteed, and farming can lose money to fees and smart-contract risk.
  • Never pay to claim a token, and claim only from a link the protocol itself publishes.
